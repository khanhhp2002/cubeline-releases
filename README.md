# Cubeline releases

Windows builds of **Cubeline**, a desktop app for learning Rubik's 3x3 algorithms with a 3D cube, a timer and Deep Solve.

Download the latest version from [Releases](../../releases/latest):

- `Cubeline_x.y.z_x64-setup.exe`: installer (recommended, updates itself)
- `Cubeline_x.y.z_x64_en-US.msi`: MSI installer (updates itself)
- `Cubeline_x.y.z_x64_portable.exe`: runs without installing (no automatic updates)

Installed copies check this repository for new versions. Each update is signed, and the app refuses any file whose signature does not match.

The builds are not code-signed for Windows, so SmartScreen may warn on first run ("More info" → "Run anyway").
